# Bevy Archive

The goal of this projec  is making it easy to find resources for bevy.
Index for all Information related to bevy.

## Outline

### Src Code Index

This Project aims to provide meta information on all the code floating around related to bevy, so u can find references and reuse code easily.

There are 3 categories of src code:

1. Bevy Engine
2. Crates
3. Snipets
4. Projects

To utilize each code i propose:

1. Bevy Engine - Integrate with
2. Crates - Integrate with
3. Snipets - Copy paste
4. Projects - Use as Inspiration

Based on this information upstreaming should be encouraged by high usage. Goal of this is to rapidly advance the bevy ecosystem.

### Blogs

Additionaly to raw code this should be the place for blug posts diving into technical details.

### Discusions

Rn discusions are handled in different channels and are hard to search. Therefore this will be inlined in this app.

### Searches

All Resoruces can be tagged and linked to other resources. Additionaly other search options will be integrated including RAG and GraphRag.
